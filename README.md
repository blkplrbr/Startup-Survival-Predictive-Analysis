# Startup Survival & Risk Factor Predictive Analysis

## Project Overview
This project acts as a Business Intelligence case study for a Venture Capital firm. The objective was to analyze historical startup data to identify the key factors that predict long-term survival, and to build a predictive model that screens incoming investment applications for risk.

## The Business Problem
VC firms and incubators need to make high-stakes investment decisions. Historically, relying solely on "gut feeling" or a founder's pitch deck leads to high failure rates. The firm needed a data-driven way to evaluate: *"What are the top predictors of startup failure, and how can we flag high-risk investments early?"*

## Dataset & Methodology
The dataset was sourced from historical startup tracking databases (e.g., Crunchbase), containing features such as:
*   Total funding raised.
*   Number of funding rounds.
*   Industry category (SaaS, FinTech, Healthcare, etc.).
*   Geographic location.
*   Target Status: **Operating (Survived)** vs. **Closed (Failed)**.

### Technical Stack
*   **Language:** Python (Pandas, Scikit-Learn)
*   **Visualization:** Power BI or Tableau
*   **Model:** Random Forest Classifier / Logistic Regression

## Key Analysis & Findings

1.  **Exploratory Data Analysis (EDA):** Discovered the baseline survival rate of the dataset and visualized which industries had the highest failure rates.
2.  **Feature Importance (The "Why"):** Utilized Machine Learning to rank the most important predictors of survival. The model revealed that [Insert your finding here, e.g., "Number of funding rounds was 3x more predictive of survival than the total amount raised"].
3.  **The Risk Screener Dashboard:** Built an interactive dashboard that allows the VC firm to input a new startup's profile and receive a "Survival Probability Score" based on the historical data.

## Business Impact
*   Transformed raw, messy startup data into a clear set of investment risk factors.
*   Provided the investment committee with a data-backed framework to evaluate potential portfolio companies.
*   Reduced the risk of investing in "solo founder, pre-revenue" startups by identifying them as high-probability failure profiles.
